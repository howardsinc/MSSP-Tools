3 — Protection Profile

👁 Trust + Alert

All scanners run, but no traffic is blocked. Detections logged to UI for visibility.

Use for: monitoring, demos, low-risk customers, pilot rollouts.

🛡 Strict Block

Prompt Injection + DLP set to alert&deny. Toxicity stays alert.

Use for: HIPAA, PCI, regulated workloads, customer trust requirements.

⚙ Custom

Per-scanner toggles + per-scanner action (alert vs alert&deny).

Use for: advanced customers, vertical-specific tuning.
